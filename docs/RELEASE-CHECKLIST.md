# 《星港拾荒者》正式版发布检查清单

本清单用于 v1.0.0 及后续版本。发布者应在提交前逐项确认，不以“网页能打开”代替完整验证。

## 版本与缓存

- `GAME_VERSION`、`PATCH_NOTES_VERSION`、HTML 元信息、页脚和更新弹窗版本一致。
- CSS、脚本、云端模块和音频 URL 使用同一缓存查询版本。
- 游戏内 Patch Notes、累计 TXT、README 与维护文档均包含本次版本。

## 存档与数据

- 当前存档、至少一个旧版存档和异常主存档均可载入。
- 存档结构变化时已递增 `SAVE_VERSION`，普通版本变化不会重复执行数值压缩。
- 手动保存、三份轮换备份、恢复最近备份、导入和导出均可用。
- 云端上传/下载失败不会影响本地存档；恢复冲突时能比较本地与云端摘要。

## 游戏回归

- 新手航路、当前航程、生产、研究、战斗、星港、远征、跃迁与奇点超越均可推进。
- 任务、活动、排行榜、公告和反馈入口不会阻塞离线核心游戏。
- 新增奖励只写入已有资源或明确的收藏字段，成本与收益不会绕过上限。

## 界面与可达性

- 390px 手机宽度无横向滚动，触控操作不会触发页面异常缩放。
- 高画质为首次默认，省电模式可手动切换并持久保存。
- 键盘可进入主要导航、跳到游戏内容、操作弹窗并看到焦点轮廓。
- 动态状态拥有文字反馈，颜色不是唯一的信息表达方式。

## 自动化与归档

```bash
node --check game.js
node --check cloud-save.js
node tests/numeric-balance.test.js
node tests/browser-smoke.test.js
node tests/mobile-performance.test.js
```

- `git diff --check` 无空白错误。
- 已生成 `历史版本/星港拾荒者-v版本号.zip`，ZIP 可读取且包含 `index.html`。
- 提交和推送前再次执行 `git status`，避免遗漏 Patch Notes、测试、文档或历史包。

## 上线后

- GitHub Actions 部署成功。
- 在线地址显示正确版本，强制刷新后资源无 404。
- Google 登录、云存档、排行榜、公告和反馈各执行一次真实检查。
- 新版本检测能识别后续补丁版本，并提示玩家刷新。
