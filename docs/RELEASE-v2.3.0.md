# v2.0.1 — v2.3.0 维护说明

本轮保持原生 HTML/CSS/JavaScript，不新增依赖、主导航或货币。

## 功能入口

- 指挥台的今日航线：主任务默认显示，可选目标折叠。
- 航线委托：累计星尘达到 1K 后展示，六种任务，UTC 每日一次选择，未完成任务跨日保留。选新任务会替代旧任务。
- 深空回响：完成远征航段取得线索，已拥有伴星后解读，再完成一次航站作业，收藏短篇。共八篇，一次性奖励。
- 归航之约：1/4/8 小时计时任务，各消耗 1/2/3 现有补给；每日发起一次，奖励不随产量放大。离线不需运行后台任务，回来按完成时间结算。
- 重建方案：显示建筑采购估价、资金缺口、记录的舰队和远征配装槽及作业清单；换装与安排作业仍由玩家确认，不绕过原费用。

深空回响与归航之约在累计星尘达到 50K 后展示，已有进度不会重新隐藏。新玩家不会开局就看到全部新入口。

## 存档与边界

继续使用 SAVE_VERSION 31；`v2.order`、`v2.echo`、`v2.returnPlan` 为兼容可选字段，sanitize 自动补齐。归航计时基于设备时钟，不作为可信排行榜分数，不承诺防篡改。

全部奖励经现有 grantExistingReward 发放，领取标记先写入内存，再同原存档一起保存。无独立云端集合。旧客户端可能丢弃不认识的新字段，因此跨设备先刷新至最新版本。

GitHub Pages 发布不等于后端部署。现有 `firestore.rules` 与可选 Functions 保持不变；没有启用付费服务。云端聚合不可用时继续明确显示“排行榜活跃玩家汇总”。
