# 3.28.0-preview.1 稳定版候选检查与游玩说明

本文为3.28目标的候选检查表，实际完成与验证状态以对应里程碑及PR精确head为准。后续用户已明确授权发布，PR #21已合并；实际Pages与公网结果见[发布验收](v328-release-validation.md)。保留preview命名，不创建GitHub Release。

## 新玩家从哪里开始

1. 首页扫描取得第一艘无人机的材料；舰队页建造后自动生产。选择本航次方向，研究与扩建按真实费用进行。
2. “下一个目标”保留一项主要工作，可直达真实操作位置。行动中心首屏最多三项就绪工作；展开“其他安排”可看需要准备、正在进行和暂时不重要。
3. 探索页先处理归航报告。重要故事和永久结局始终手动选择，三个结局要预览并最终确认；无隐藏善恶门槛。
4. 第一次至第四次跃迁依次取得自动购买、预算/优先级、自动研究和重复安全派遣。跃迁保留永久故事、结局、舰装、档案和经营。
5. 结局后按自己的节奏接居民需求、建设长期工程、调查图谱、复查证据与安排四阶段远航。没有每日上线、到期失败或离线惩罚。

## 存档兼容与恢复

仍为schema32。新增惰性可选`continuation.links`；新编排远航可选`condition`、各段可选`condition/schedule`。没有这些字段的旧档保留原状，旧已付航程不重新报价，不重置任何章节、选择、结局、装备/方案、探索/调查、首航、居民/工程、荣誉或收藏。

前台每5秒保存；切至后台和离开页面时保存，隐藏期间不反复渲染/写入，返回或重开按既有最多8小时规则补算。自动备份每5分钟轮换3份，手动/恢复前另3份；缓存只避免重复解析未变化的自动备份，主存档的预期文本校验和写后校验始终执行，任何备份字节变化会重验。

导入先预览章节、结局、资源、协作、荣誉和资料用途；只是替换完整记录，不合并或叠加资源。较早记录或不同选择会提醒。另一窗口更新、未来schema、损坏数据或备份失败按原安全规则停止覆盖。重要节点仍建议导出JSON留存。

## 已知验证限制与判断

云内WebKit官方安装域名403，必须与GitHub容器中的WebKit结果分别记录；真实iPhone Safari与实际手机软键盘没有操作。320/375px是隔离浏览器视口，不是真机。30分钟挂机为可重复虚拟时间负载与Chromium堆采样，不冒充30分钟真实设备老化试验或长期内存无泄漏证明。

技术上应以全部全量与双引擎检查为候选门槛；真实Safari、实际低端手机与真实长时间会话仍需补验。建议保持preview作为稳定候选，完成这些实机检查及发布审批后再决定结束preview。保留preview命名，发布执行情况见3.28发布验收。
