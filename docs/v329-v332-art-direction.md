# 视觉制作与来源

本轮使用 OpenAI Image Gen 原创生成完整七页/手机概念，以及八张不同主体的电影感场景和一张四道具图集。没有从图库或其他游戏取图。全尺寸生成 PNG 留在工作区工具输出，不进入运行包；实际游戏使用仓库内 WebP。准确文件大小、尺寸、源名称见 `v3/assets/manifest.json`；本项目原有 salvage-orbit.webp 另有两张响应式派生，不能计为新增原创主体。

## 八张场景的实际生成简报

统一简报：原创电影感硬科幻环境，实用、风化的工业拾荒世界，真实材质，深蓝阴影、琥珀工灯与克制青光；主体居中可手机裁切，无文字、标识、水印或界面。

1. orbital-dock：开放轨道船坞、拾荒拖船、龙门吊与机械臂，舱外破损轨道环。
2. production-line：废船壳板回收产线、多关节机械臂、熔炉、输送轨与金属容器。
3. sector-nebula：青蓝星云、紫色尘埃、微小拾荒艇、月面与废导航柱；留出可叠加真实图谱的深空区域。
4. voyage-bridge：空船长座椅、全景舰桥、气态巨星和轨道环，青色导航台与琥珀仪表。
5. wreck-investigation：两名调查员与扫描无人机检视破损医院船，冰霜、裂梁与仍亮着的应急灯。
6. resident-habitat：旋转居住舱街道、暖窗、公共餐桌、维护者、居民与植物，舱外行星。
7. ecology-greenhouse：修复的空间站温室、水培蔬菜、幼苗、种植者、管线和星空玻璃顶。
8. starcore-jump：三重巨型旧机械环包围明亮星核，紫蓝空间弧线，拾荒船准备通过。

四道具图集：橙色拾荒拖船、储能模块、带温室照片的旧通信与磁带、古铜灯塔荣誉章。拖船另做隔离剪影细化，用于动画时保持完整轮廓。图集先按象限提取，再独立 trim 与压缩；首轮 sharp 管线顺序错误的原始失败已保存，未以损坏裁切图交付。

## 概念与实装差异账本

概念用于锁定材质、五种语言与七种构图，不覆盖游戏现有信息架构。明确保留原来左侧导航、中文标题/命令、真实目标栏、扫描与经济，而非采用图中虚构的指标和操作。七页都必须是原生可操作界面；旧探索聚合仍作为兼容入口。图谱保留现有三条九节点，地图背景不生成虚假路线。原图谱与星港SVG继续精确解释状态，电影场景承担叙事与氛围。

对照验收关注：五种色光一致；船坞/大图谱/舰桥/阅读栏/陈列/核心构图有差异；图像不盖住按钮；中文层级和留白清楚；手机有独立裁切和触摸结构。人工查看与自动化可用性分开记录，不以像素或脚本通过冒充主观美术评分。
