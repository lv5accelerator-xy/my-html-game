早期版本在游戏界面中可能仍显示旧的内部标识“航站协议 v1.0”；正式版本号以 ZIP 文件名和 Patch Notes 为准。

## 文档存档

以下三个版本的原始可运行源码快照未在当前工作区或 Git 提交历史中找到，因此只保存对应版本说明，没有使用后续版本伪装成旧版本：

- `星港拾荒者-v0.1.0-文档存档.zip`
- `星港拾荒者-v0.7.1-文档存档.zip`
- `星港拾荒者-v0.8.0-文档存档.zip`

每个文档存档内包含：

- `ARCHIVE-INFO.txt`：档案状态与缺失说明。
- 对应版本的独立 Patch Notes。

如果以后找回上述版本的原始 ZIP，可直接用原始文件替换相应文档存档。
