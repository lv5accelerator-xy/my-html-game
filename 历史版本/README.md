## 文档存档

以下三个版本的原始可运行源码快照未在当前工作区或 Git 提交历史中找到，因此只保存对应版本说明，没有使用后续版本伪装成旧版本：

- `星港拾荒者-v0.1.0-文档存档.zip`
- `星港拾荒者-v0.7.1-文档存档.zip`
- `星港拾荒者-v0.8.0-文档存档.zip`

每个文档存档内包含：

- `ARCHIVE-INFO.txt`：档案状态与缺失说明。
- 对应版本的独立 Patch Notes。

如果以后找回上述版本的原始 ZIP，可直接用原始文件替换相应文档存档。

## 后续版本归档规则

从 v0.9.3 之后，每次发布新版本时必须同步执行：

1. 修改游戏前，先确认当前旧版本已有可运行 ZIP。
2. ZIP 统一命名为 `星港拾荒者-v版本号.zip`，并放入本目录。
3. 完成新版本后生成对应的新版本 ZIP，为下一次更新保留完整快照。
4. 逐个验证 ZIP 可以正常读取，并确认包含游戏入口文件。
5. 同步更新游戏内版本号、游戏内更新记录和累计 Patch Notes TXT。
6. 将游戏代码、Patch Notes 与历史版本 ZIP 一并提交到 GitHub。

不得用后续版本改名冒充缺失的旧版本；如果原始快照确实遗失，必须明确标注为文档存档。
